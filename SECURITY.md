# Security

Caobunga is a personal project shared as-is, so security fixes are best-effort with no response-time promise.

To report a vulnerability, use this repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting: `https://github.com/fakeneuron/caobunga/security/advisories/new`). Please don't open a public issue for one.

Caobunga launches coding CLIs you have already authenticated and runs them against repos you register. Read [docs/CONTRACT.md](docs/CONTRACT.md) before pointing it at anything you care about.
